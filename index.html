스마트팜 AI 에이전트 — 함수 호출(Function Calling) 신뢰성 시연

자연어 명령을 입력하면 에이전트가 정의된 함수(조회 기능) 중 어떤 것을 호출할지 결정하는 과정을 단계별로 보여줍니다. 시뮬레이션 모드는 보고서의 4가지 오류 유형(비정의 호출·메타질문 처리실패·개념 혼동·과잉 호출)이 어떻게 발생·완화되는지 키워드 기반 mock 로직으로 보여주는 개념 시연이고, 실제 API 연동 모드는 진짜 OpenAI 함수 호출 결과를 보여주며, 로컬 파이썬 서버(server.py)로 연결하거나 본인의 API 키를 직접 입력해 웹(GitHub + Vercel 배포)에서 바로 실행하는 두 가지 방식을 지원합니다.

등록된 함수 (조회 전용)

get_internal_sensor()

내부(하우스) 온도·습도 조회

get_external_sensor()

외부 환경 — CO₂·습도·기온 조회

get_crop_status()

작물 생육 상태(수확 시기 포함) 조회

get_now_time()

현재 날짜·시각 조회

※ get_weather 등은 정의되지 않은 함수입니다. 아직 스마트팜에서 무엇을 제어(actuator)할지 결정되지 않아, 이번 단계는 4개의 조회 함수만으로 "함수 선택 신뢰성" 문제에 집중합니다.
